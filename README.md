# Todo Notes

SPA-приложение для заметок со списками задач.

## Запуск в Docker

```bash
docker-compose up --build
```

Открыть приложение: http://localhost:3000.


## Локальный запуск

Требуются Node.js 24 и pnpm.

```bash
pnpm install
pnpm dev
```

Приложение будет доступно по адресу http://localhost:3000.

## Проверки

```bash
pnpm test
pnpm typecheck
```
